Capabilities

Artifacts
Lets the model build web pages, small apps, SVG graphics and long documents in a panel next to the chat, where you can preview, copy and download them. When off, it writes code as plain text in the reply instead.

Memory

Search and reference chats
Lets the model look up relevant parts of your past chats when you mention them. Matching excerpts are added to the model's context, which uses a few more tokens per message.
Generate memory from chats
After each reply, the model saves lasting facts you share about yourself and uses them in every chat. This adds one short model call per reply. Turning it off stops both saving and using memory; saved memories stay until you delete them.

    Export data
